# KORIA

Private travel, simplified.

Cinematic marketing website for KORIA — the consumer layer for private aviation.

## Stack

Next.js, TypeScript, Tailwind CSS, GSAP + ScrollTrigger, Lenis, React Three Fiber, Three.js

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
```

This produces a static export in `out/` for GitHub Pages.

Live site: [https://agarcia246.github.io/hopp/](https://agarcia246.github.io/hopp/)
